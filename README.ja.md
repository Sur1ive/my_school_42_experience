## Piscine の課題
piscine は1ヶ月の短期決戦で、瞬発力と時間配分が問われる。時間は絶対に足りないし、全課題をやり切るのはほぼ無理。戦略を取った方がいい。たとえば一部の課題の最終問は難易度が一段上がるアルゴリズム問題なので、満点を狙わずに飛ばすのが無難。最後に余力があれば戻って満点を取りに行けばいい。

合否は試験点だけで決まらないので、exam の点数にこだわりすぎないこと。課題を進めつつ、イベントやチーム課題にも出て、人と絡む。それが合格率を上げる一番の近道。
