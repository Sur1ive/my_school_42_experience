## Piscine Projects
piscine是一个月的短线战斗，考验爆发力和时间分配。时间一定是不够用的，基本上没法做完所有课题。可以采取一些策略，例如有些课题的最后一题是难度高一大截的算法题，稳妥的做法是不追求满分直接跳过，到最后如果有余力可以回头刷成满分。

最后是否录取不止是看exam成绩，因此不用过度在意exam的分数。尽力推课题进度的同时请多参加活动和团队课题，多社交，这样可以最大化录取率。
